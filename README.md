# 🌐 Website Koperasi Kelurahan Mimbaan

Website ini merupakan media informasi digital untuk membantu masyarakat dalam mengakses layanan yang tersedia di Koperasi Kelurahan Mimbaan.
Project ini saya kembangkan sebagai bagian dari kontribusi langsung dalam kepengurusan inti koperasi.

---

## 📌 Deskripsi Project

Website ini dirancang untuk menyediakan informasi yang jelas, mudah diakses, dan responsif terkait layanan koperasi, seperti:

* Informasi profil koperasi
* Layanan yang tersedia
* Informasi kontak dan lokasi
* Media komunikasi antara koperasi dan masyarakat

Project ini bersifat **statis** dan dibangun dengan pendekatan **frontend-focused development**.

---

## 🎯 Tujuan Pengembangan

* Meningkatkan akses informasi bagi masyarakat
* Mendukung digitalisasi layanan koperasi
* Menghadirkan tampilan yang sederhana, informatif, dan user-friendly

---

## 🛠️ Tech Stack

## ✨ Fitur Utama
